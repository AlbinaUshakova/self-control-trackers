# Privacy Policy Source

This repository publishes the user-facing privacy page at `privacy.html`.

Current policy summary:

- Data stored: meal entries, goals, selected language, and local notice flags
- Storage location: browser `localStorage` on the user's device
- Account: no account required
- Server storage: no server-side meal history storage in this repository
- Sync: no built-in sync between devices
- Retention: 21 days of meal history

If implementation details change, update both `privacy.html` and this file in the same change.
