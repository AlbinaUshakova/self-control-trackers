EatLog Privacy

Конфиденциальность EatLog

EatLog stores meal history, app settings, onboarding flags, and goals locally in your browser using localStorage. The current web app does not require an account.

EatLog хранит историю приемов пищи, настройки приложения, флаги онбординга и цели локально в браузере через localStorage. Для текущей веб-версии аккаунт не нужен.

What is stored

Что хранится

  • Meal entries: date, time, note, and whether the entry is a snack.
  • Daily goals and display preferences, including the selected language.
  • Local UI flags, such as whether welcome or update notices were already shown.
  • Записи о еде: дата, время, заметка и отметка, является ли запись перекусом.
  • Цели на день и настройки отображения, включая выбранный язык.
  • Локальные служебные флаги, например были ли уже показаны welcome- и update-уведомления.

Where it is stored

Где это хранится

Data is stored on the current device and in the current browser profile. The app also caches static files through a service worker so the shell can open offline after an online visit.

Данные хранятся на текущем устройстве и в текущем профиле браузера. Приложение также кеширует статические файлы через service worker, чтобы оболочка могла открываться офлайн после онлайн-визита.

Server, sync, and retention

Сервер, синхронизация и хранение

  • No account is required.
  • No built-in cross-device sync is implemented in this repository.
  • No application server is used for storing meal history.
  • Meal history is retained for 21 days.
  • Аккаунт не требуется.
  • В этом репозитории нет встроенной синхронизации между устройствами.
  • Сервер приложения не используется для хранения истории приемов пищи.
  • История приемов пищи хранится 21 день.
