EatLog Privacy

EatLog stores meal history, app settings, onboarding flags, and goals locally in your browser using `localStorage`. The current web app does not require an account.

EatLog хранит историю приемов пищи, цели и служебные настройки локально в браузере через `localStorage`. Аккаунт для использования приложения не нужен.

What is stored

  • Meal entries: date, time, note, and whether the entry is a snack.
  • Daily goals and display preferences, including selected language.
  • Local UI flags such as whether welcome or update notices were already shown.

Where it is stored

Data is stored on the current device and in the current browser profile. The app also caches static files through a service worker so the shell can open offline after an online visit.

Server, sync, and retention

  • No account is required.
  • No built-in cross-device sync is implemented in this repository.
  • No application server is used for storing meal history.
  • Meal history is retained for 21 days.
